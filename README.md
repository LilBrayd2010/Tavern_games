# Tavern_games
A D&amp;D-themed collection of fun games with fake currency—including blackjack, poker, and custom fantasy-inspired games. Built for friends to enjoy together!


## How to Play

### Blackjack
1. Go to the Tavern
2. Select Blackjack
3. Place your bet in Gold Pieces
4. Hit or Stand to play against the dealer
5. Beat 21 without going over to win!

## Technology

- **HTML5** - Structure
- **CSS3** - Styling
- **Vanilla JavaScript** - Game logic
- **LocalStorage** - Player data persistence

# Tavern Games 🍺🎲

A D&D-themed collection of fun games with fake currency—including blackjack, poker, and custom fantasy-inspired games. Built for friends to enjoy together!

## Features

### 🎮 Games
- **Blackjack** - Classic card game against the dealer
- **Poker** - Coming soon!
- **Dice Roller** - Roll D&D dice and compete
- **Rune Stones** - Fantasy-themed luck game

### 💰 Currency System
- **Daily Allowance**: 10 Gold Pieces per day
- **Exchange Rates**:
  - 1 Gold Piece (GP) = 50 Silver Pieces (SP)
  - 1 Silver Piece (SP) = 100 Copper Pieces (CP)
  - Therefore: 1 GP = 5,000 CP

### 👤 Player Features
- Create unique characters with classes (Warrior, Rogue, Mage, Cleric, Bard)
- Track your wealth and game stats
- Leaderboard to compete with friends
- Local data storage (no server needed!)

### 🎨 D&D Tavern Aesthetic
- Medieval tavern theme
- Golden accents and dark atmospheric design
- Fantasy-inspired UI elements
- Responsive design for mobile and desktop

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Create a character
4. Claim your daily 10 Gold Pieces
5. Start playing!
